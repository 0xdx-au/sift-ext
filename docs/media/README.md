# SIFT imagery / ADMINE brand alignment

These SVGs are original project compositions built around the **exact Contour-A silhouette and layered topographic mark** from `0xdx-au/cf-website-main/public/brand/admine-mark.svg`, using design tokens from `src/styles/global.css` and guidance in `docs/brand-identity.md`.

- Dark: `#101010` background, `#e9e7e1` text, `#c7a86b` muted gold accent
- Light: `#f5f4f0` background, `#20211f` text, `#80591f` muted gold accent
- ADMINE contour-A spur: `#57dcc1` on dark, `#087963` on light; the fixed symbol silhouette **must not change**
- Topographic lines are subtle, thin, static; no glow, animated logo, or security status colour implied by branding
- Type: system sans for headlines and system monospace for technical metadata

`sift-hero.svg` and `sift-flow.svg` are dark variants; `*-light.svg` are light variants selected using GitHub's preferred-colour-scheme media query. `sift-mark.svg` is a source-aligned square project mark.

These are **illustrations, not screenshots or proof of released functionality**. Do not substitute the artwork for real installed-browser verification.
