# SIFT visual assets

These self-contained SVGs are ADMINE-authored **project illustrations** for the GitHub README, not browser screenshots or proof of a released product.

- `sift-hero.svg`: project masthead using dark charcoal and teal topographic signal styling
- `sift-flow.svg`: public trust-boundary illustration, explicitly marking signed delivery as planned
- `sift-mark.svg`: square mark suitable for a GitHub repository social-preview image after separate owner configuration

No external fonts, remote images, tracking pixels, embedded scripts or proprietary logos are loaded. Generated screenshots of real installed-client builds should be separately reviewed, dated, linked to their exact commit and added only after checking that they display no private data. Do not publish unattended CI build credentials to commit image artifacts.
